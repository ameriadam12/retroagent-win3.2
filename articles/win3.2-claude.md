# 我在 1994 年的 Windows 3.2 里,和 Claude 聊上了

我一直有个念头:那些老到掉渣的 Windows,能不能也用上现在的 AI?

不是整活。是真想。Windows 3.2,1994 年的简体中文版,16 色,640×480,没网,内存按 KB 算。它当然跑不了 Claude Code——Node 都没地方装。但换个思路:Claude 不必真跑在里面,只要让坐在 Win3.2 跟前的人,能问、能看回复,就行了。

中间怎么连?

串口。1980 年代的技术,Win3.2 当然认。

## 搭了这么个东西

```
Win3.2 桌面 ──COM1 串口──> QEMU 虚拟串口 ──unix socket──> 一个 Python 小桥 ──> claude 命令行
```

Win3.2 这头,用户敲一行 `ASK 你好`;Linux 那头,Claude 收到、回话,再顺着原路扔回来。

听起来简单。做起来全是坑。

## 装个 DOS,耗了一晚上

介质是从网上扒的 MS-DOS 7.1 安装光盘(中国 DOS 联盟那个版本),丢进 QEMU 启动。然后——CDU 的安装向导,十几个中文对话框,欢迎、许可、分区、格式化……我让 QEMU 自动按键走流程,结果按键全没反应。

查了半天才反应过来:**QEMU 8.2 的 send-key 命令改格式了。** 旧文档都说 `keys:["ret"]`,新版非要 `keys:[{"type":"qcode","data":"ret"}]`——传裸字符串它默默拒掉,一个字不发。我盲按了半天 Enter 和 `n`,差点以为键盘坏了。

还有读屏。DOS 安装界面是中文图形,截图我看不到(图传 CDN 不回显)。但 VGA 文本缓冲区在内存 `0xB8000`,80×25 个字符,每字符俩字节。我把这 4000 字节 dump 出来,按 GBK 一解——

```
5|   MS-DOS 7.10 Setup          [x]
7|   Welcome to MS-DOS 7.10 Setup.
```

中文菜单清清楚楚。就靠这招,我一个对话框一个对话框地走完了整个 DOS 安装:分区、格式化、重写 MBR、解包系统文件……全自动,没用一次手。

## Win3.2 倒是顺利

网上找的 `win32c.zip` 是已经装好的文件树(不用软盘 setup),直接把 `WINDOWS/` 整个拷进 C 盘就行。`win` 一敲——

桌面起来了。中文正常,程序管理器在那儿,16 色,像素粗得像马赛克。一瞬间有点穿越的恍惚。

(拷文件也有个小波折:QEMU 跑着的时候改不了镜像,没 root 又用不了 libguestfs。最后用 mtools 直接操作 raw 镜像里的 FAT16 分区——`mcopy -i image@@32256 ...`,`32256` 是分区起始字节偏移,这么个土办法。)

## 然后是真正卡我的地方

给 Win3.2 写个串口客户端。

本来想自己编译一个——Open Watcom,开源的 Win16 编译器,写了个带输入框、显示框、发送按钮的小程序。编译成功,EXE 生成正常。

一跑,**黑屏**。加载就崩。

我换成 Open Watcom 官方示例(就一个 MessageBox 那种 hello world),也崩。折腾半天认了:**Open Watcom 生成的 Win16 程序,在这个 Win3.2 中文版 + QEMU 的组合下,加载阶段就出问题。** 工具链的兼容性硬伤,不是我的代码 bug。要深挖能解决,但我先放下了。

最后用的是 **Win3.2 自带的 Terminal.exe**。微软原版,147KB,确定能跑。打开,Settings 里选 COM1、9600、8N1,勾上 Local Echo(看自己敲的字)和 Line Wrap(自动换行)。

敲:

```
ASK Windows 3.2 是哪一年发布的
```

回车。

```
> ASK Windows 3.2 是哪一年发布的

*Thinking

(一段完整的中文回复,自动换行)
```

## 通了

1994 年的桌面,2026 年的 AI,在一根虚拟串口线上,把话接上了。

中间那个 `*Thinking` 是我加的——Claude 思考的时候显示一下,让你知道它在干活、不是卡死。本来做过流式(一边生成一边逐字蹦),但跳得有点烦,改成了:思考时显示 Thinking,想完一次性吐完整段。反而更像老终端的节奏——敲一下,顿一下,然后一段完整文字出来。

## 说点感想

这玩意儿没什么实用价值。没有人真会在 Win3.2 里写代码。

但它有意思在——把两个隔了三十年的世界,用最朴素的方式接了起来。串口,1980 年代的标准,老到不能再老;AI,2026 年的最前沿。中间踩的每一个坑(QEMU 改了 send-key 格式、VGA 要手动读、CDU 安装盲走、Open Watcom 加载崩、Terminal 默认不回显……)都是"文档说能、实际不行",得自己一点点摸。

然后看到 Claude 的字出现在那个 16 色的窗口里——

突然就值了。

技术是累积的。今天的 AI 站在几十年的操作系统、网络、硬件上。但老系统没死,它们就那么安静躺着,看你会不会回头找它。

Windows 3.2 不会用 Claude Code。

但 Windows 3.2,可以和 Claude 说话。
